# TitraDeck 功能与模型范围

本文对应 1.0.0。工具以离线计算为主，所有结果展示原始公式、主要计算步骤、单位和适用条件。这里列出实际实现范围，避免将教学近似或在线数据理解为通用化学推理系统。

## 计算模块

### 化学基础

| 功能 | 输入与输出 | 模型与限制 |
| --- | --- | --- |
| 化学式解析 | `C₆H₁₂O₆`、`Fe₂(SO₄)₃`、`CuSO₄·5H₂O`、嵌套 `()`/`[]`/`{}`；输出元素计数、摩尔质量、各元素质量贡献及质量分数 | 覆盖 118 元素、Unicode 下标、晶体水、常见相态和离子电荷。使用平均原子量，不解析同位素标记，也不计算单同位素精确质量。 |
| 方程式配平 | 用 `+` 分隔物种、`->`/`→`/`=` 分隔两侧；自动给出最简正整数系数，并列出元素与电荷守恒核验 | 使用精确有理数高斯消元。支持有机/无机及离子反应、复杂括号、晶体水、电子；无解、多个独立解或必须出现零/负系数时明确拒绝。只配平给出的物种，不推断生成物或反应可行性。 |
| 化学计量 | 自动配平方程式；按行录入反应物质量、物质的量、气体体积或粒子数；输出消耗/生成量、剩余投料、极限反应物及可选产率 | 质量用 `n=m/M`，气体用给定绝对温度/压力的 `PV=nRT`。只有输入全部反应物才进行完整极限投料判断；未录入反应物明确视为足量。 |
| 由产物反推 | 可仅输入一种理论生成物的量，反推其余物种的化学计量对应量 | 不据此判断实际投料的极限反应物，也不将该理论量同时当作实测量计算产率。 |
| 产率 | 反应物投料求理论量，再输入指定生成物实际产量 | 产率超过 100% 会提示检查纯度、含水量和测量误差，不静默截断数值。 |
| 经验式/分子式 | 输入全部元素质量百分比；可指定摩尔质量求分子式 | 在用户给定组成偏差内搜索小整数比，分母范围 1–24；经验式受分析精度限制。分子式质量应与经验式量的整数倍在 1% 内相符。 |
| 单位换算 | 质量、体积、物质的量、粒子数、摩尔/质量浓度、压力、温度 | 跨质量浓度与摩尔浓度需提供摩尔质量；不允许任意不同量纲直接换算。切换单位保留输入并刷新结果，点击按钮保存到历史。 |

离子推荐使用无歧义写法，例如 `SO4^2-`、`Fe^3+`、`e^-`；也接受 Unicode 上标电荷以及 `NH4+`、`Fe3+` 等常见写法。相态可写为 `(s)`、`(l)`、`(g)`、`(aq)`。

化学计量输入示例：

```text
方程式：H2(g) + O2(g) -> H2O(l)
已知量：
H2: 4 g
O2: 32 g
实际生成物：H2O
实际产量：30 g
```

支持 `kg`、`g`、`mg`、`μg`、`mol`、`mmol`、`μmol`、`L`、`mL` 和 `个`。气体体积使用单独标明的 K 与 Pa 条件；只有气态物种或作为气体体积输入的物种才展示体积结果。数量、下标、嵌套深度和方程式规模设有边界，错误输入不返回部分配平结果。

### 溶液与酸碱

| 功能 | 实现内容 | 适用范围 |
| --- | --- | --- |
| 浓度换算 | 摩尔浓度 M、质量摩尔浓度 m、当量浓度 N、质量分数相互换算 | 需要溶质摩尔质量、实际溶液密度及反应当量因子。N 与具体反应有关，不由化学式唯一决定。 |
| 稀释配液 | `C₁V₁=C₂V₂`，任选未知量 | 校验原液浓度不低于目标浓度。输出取液量和最终定容体积，不把差值当作精确加水体积。 |
| 混合 | 两份同一溶质溶液的混合浓度，可输入实测最终体积 | 假定不发生反应或沉淀；未输入最终体积时采用体积相加近似。 |
| 质量/体积分数 | 组分量与混合物总量求百分比 | 分母是混合物总量；体积分数需采用一致的温度及体积定义。 |
| 强酸/强碱 pH | 输入 H⁺/OH⁻ 当量分析浓度及 pKw，输出 pH、pOH、[H⁺]、[OH⁻] | 保留水的自电离，极稀酸碱和零分析浓度趋于对应温度下的中性。 |
| 弱酸/弱碱 pH | 输入单质子弱酸 pKa 或单碱弱碱 pKb，求物料/电荷守恒解和电离分数 | 单一弱酸/弱碱、稀溶液活度近似。未实现多元酸逐级电离、缓冲混合体系及高离子强度活度修正。 |

### 平衡与电化学

| 功能 | 实现内容 | 适用范围 |
| --- | --- | --- |
| 能斯特方程 | 输入 E°、转移电子数、T、Q；或将 H⁺ 指数与 pH 纳入 Q，求 E | Q 与 E° 必须对应同一反应方向，活度应无量纲；输入电池总反应参数时可求电池电动势。 |
| 电解 | 恒定电流、时间、电子计量数、摩尔质量及电流效率，求电荷、电子量和产物量 | 反应已明确；变电流需先求积分电荷，副反应由电流效率近似修正。 |
| Kc/Kp | 根据温度及气体计量数变化双向换算 | 采用 c°=1 mol/L、p°=1 atm 的明确标准态；适用于理想气体组分。 |
| 反应商 Q | 按活度和系数计算 Q，比较 K 判断趋近平衡方向 | 不求通用多组分平衡组成，不根据浓度推断未知反应。 |
| Ksp | 二元盐 `AₐBᵦ` 在纯水或已有同离子溶液中的摩尔/质量溶解度 | a、b 为 1–6 的整数；固体足量，忽略酸碱、络合和活度副作用。过饱和初态明确报错，不误作继续溶解。 |
| 配合物平衡 | `M+L⇌ML`，由 Kf 与两种分析总浓度求游离量和配合率 | 单一 1:1 配合物模型；不包含多级配位、质子化、水解或竞争络合。 |

### 物理化学

| 功能 | 实现内容 | 适用范围 |
| --- | --- | --- |
| 理想气体 | P/V/n/T 知三求一；Pa/kPa/atm/mmHg/bar、L/mL/m³、K/°C 换算 | 使用绝对压力和绝对温度，排除非正已知量；高压或近液化条件需真实气体模型。 |
| 阿伦尼乌斯 | 两温度速率常数求表观 Ea，或由 Ea 预测 k₂ | 假定机理、指前因子和活化能在温区内近似不变；k₁、k₂ 必须同单位。 |
| 一级动力学 | 半衰期与 k 互求，或求随时间衰减的浓度 | 不可逆一级或条件固定的准一级反应，不用于零级/二级反应。 |
| 盖斯定律 | 输入多条反应说明、乘数和焓变，求指定线性组合的 ΔH | 负乘数对应逆反应。用户提供组合系数；工具不自动求目标反应的组合，不自动校验描述中的物相和配平。 |

### 结构与有机教学工具

| 功能 | 实现内容 | 适用范围 |
| --- | --- | --- |
| VSEPR | 根据成键电子域与孤对数预测电子域几何、分子构型和理想键角；给出可旋转示意 | 单中心主族、2–6 个电子域，双/三键各计一个域；不从任意分子式自动推断中心原子/孤对，不适用于过渡金属配合物。 |
| 不饱和度 | `DBE=(2C+2+N−H−X)/2`，X=F+Cl+Br+I | 常规价态中性闭壳层 CHNXO/S 化合物。 |
| 化合物查询 | 通过名称、分子式、SMILES 或 CID 在线查询 PubChem，每页 20 个候选。详情显示二维结构图，可切换至分子模型。 | 中文名称直查无匹配时通过 MyMemory 翻译，界面显示实际使用的译名。二维图使用 PubChem 的结构描绘，分子模型优先使用 3D 构象，缺少 3D 时使用 2D 坐标。 |

## 参考模块

- 118 元素周期表可水平滚动、按名称/符号/序数检索并点击查看详情。元素详情包括原子量、序数、电子排布、电负性、常见氧化态、半径、熔沸点及来源；缺失数据保持缺失。
- 标准原子量使用 CIAAW 简明表，其他性质来源为 PubChem；没有标准原子量的元素标明使用代表同位素质量。物性与实验条件、压力和同素异形体有关。
- 常数库含 SI 定义常数及派生值、示例 Ka/Kb、Ksp、Kf 和标准电极电势，显示来源及条件。适用条目可直接填入对应计算工具，也可复制数值。
- 数据快照来源和模型说明详见 [DATA_SOURCES.md](DATA_SOURCES.md)。应用运行不请求这些网站；维护者的数据更新脚本才需要联网。

## 输入、结果与历史

1. 在「计算」按分类或搜索进入工具。
2. 查看原始公式、选择待求变量/模式，按字段填写数值、单位与条件；有关联常数的字段可以引用参考值。
3. 结果显示计算值、单位、步骤和适用条件；错误输入显示原因，不将 `NaN`/`Infinity` 当作有效结果。
4. 成功的手动计算自动写入本机 SQLite；实时单位切换只更新预览，保存操作才写入历史。
5. 「历史」保存工具、输入、结果、原始公式、步骤和时间，可按工具名称/输入搜索，一键恢复输入及结果后修改，也可确认清空全部记录。

历史和外观偏好仅保存在本机。应用无账号、无云同步；卸载或清除应用数据会删除记录。结果复制方便转入笔记，但显示位数不代表超出原始数据或测量输入精度的准确度。

## 外观与系统适配

应用使用一套 Material 3 界面，不按 Xiaomi、OPPO、vivo、HONOR、Meizu 等厂商切换布局或控件。Android 12 及以上读取系统动态主题色，较早版本使用内置配色；设置页提供跟随系统、浅色、深色三种外观模式。

背景有「跟随系统背景」和「自定义背景」两种状态。自定义背景接受 `#RRGGBB` 或 `RRGGBB`，也可直接选择六个预设颜色。应用保存精确 RGB 值，同时根据背景亮度选择合适的表面层级，并调整文字、主要控件和系统栏图标的对比度；切回系统背景会清除自定义值。

底部导航四项均使用固定 24 dp 矢量图标，项目等宽，图标和标签居中，选中状态只改变颜色与容器，不改变图标尺寸。
## 未包含的通用能力

联网反应搜索属于可选扩展，本版未接入；核心功能因此可完整离线运行。本版也未实现自动预测反应产物、任意多组分/多级平衡求解、通用 Lewis 自动生成、量子化学结构优化或完整构象搜索。上述限制在相应工具中明确呈现。
